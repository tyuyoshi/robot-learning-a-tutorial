## 今回の学習目的

- ロボット学習の考え方を、日本語で自分の言葉で説明できるようにする。
- 小さなコード実験で理論とデータ・動作を結び付ける。
- 購入した実機のセットアップから、データ収集・学習・評価へ段階的に進む。

## 対話での進め方

- 2026-09-13 更新：学習者はデータサイエンティスト歴8年。Python・機械学習の基礎は質問を投げず、回答付きで簡潔に扱う。ロボット固有の部分を丁寧に説明し、まず SO-101 の実機操作を優先する。
- ロボットの理解確認は原則3問のうち2問を回答付き、1問を学習者が回答する形にする。細かさを削るのではなく、問いに答えの一部やヒントを添える。
- PDF の順に、一回一つの話題を扱う。短い説明 → 身近な例 → 一つ確認する質問 → 回答に応じた補足を基本とする。
- 日本語で説明し、英語の専門用語は初出時に併記する。数式は記号の意味と具体例から説明する。
- 既知の内容は短く、前提が足りない箇所はその場で補う。理解したと確認できるまでは「理解済み」と記録しない。
- コーディングは予想・実行・結果の解釈を一緒に行う。実装を先回りして完成させすぎない。
- 実機実習は機種と準備状況に合わせて挟む。第1章のデータ収集例は、機種確認・組立・接続・校正・基本操作の確認後に実行する。
- ライブラリを使う段階で公式の現行手順と教材コードを照合し、利用バージョンと実行方法を記録する。
- 一回の学習の要点と未解決点を残し、意味のある区切りで commit / push する。
- Notion は問いと用語の解説をストーリー順に並べる。用語名だけで済ませず、意味・具体例・似た概念との違い（例：汎化性能と頑健性）をその問いの場所に残す。
